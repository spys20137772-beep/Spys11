# 👻 빙의 대소동 (Roblox판)

[원작 웹게임](https://spys20137772-beep.github.io/spys9/)(2D 픽셀)을 로블록스 3D로 옮긴 버전.

## 실행
레포 최상위의 `BinguiGame.rbxlx`를 Studio에서 열고 ▶ 플레이.
(코드를 고친 뒤 다시 만들기: `python3 tools/build_place.py bingui BinguiGame.rbxlx`)

## 조작
| | PC | 모바일 |
|---|---|---|
| 이동 | WASD | 왼쪽 조이스틱 |
| A: 몸의 능력 | 클릭 / J (누르고 있으면 연사) | 보라색 A 버튼 |
| B: 빙의·순간이동 | E / K | 흰색 B 버튼 |
| 고유 스킬 | Q | 파란 버튼 |
| 상호작용 | F | 노란 버튼 (물건 근처에서 표시) |

## 옮긴 것
- 영혼 혼이: 벽 통과, 시간이 지나면 흩어짐, 체력 하트, 도약
- 빙의: 몸에 닿거나 B로 바라보는 몸(흰 테두리)에 순간이동. 몸은 시간이 지나면 쓰러짐
- 몸 15종과 각자의 능력(A)과 고유 스킬: 시민, 쥐, 고양이, 비둘기, 과학자, 경찰, 경찰견, 퇴마사, 군인, 보안 로봇, 실험체, 자동차, 경찰차, 탱크, 대퇴마사
- 9x9 도시: 주택, 공원(분수), 시장, 경찰서, 학교, 카페, 마트, 병원, 은행, 주유소, 연구소·군사기지(담 + 문)
- 건물 파괴 → 2분 뒤 재건. 소품 파괴 (드럼통·주유기는 폭발)
- 상호작용: 냉장고(회복), 경찰서 컴퓨터(경계 0), 침대, 커피(속도), 수조(실험체 탈출), ATM
- 경계 1~5단계와 단계별 출동 (경찰 → 경찰견·경찰차 → 퇴마사 → 군대 → 로봇·탱크)
- 변장 (아무도 안 볼 때 몸을 바꾸면 경계 하락), 경찰견·퇴마사의 냄새 맡기
- 밤낮 (밤에 퇴마사 순찰), 경계 5단계를 25초 버티면 대퇴마사 등장 (약해지면 빙의 가능)
- 미션 17개, 진화 업그레이드 9종, 구역 장악 (81구역), DataStore 저장

## 아직 안 옮긴 것
하수구 지하 세계, 의뢰 게시판, 도감·스킨, 소방차·구급차·헬리콥터·악어, 물건 들어서 던지기, 불, 날씨, 사운드(에셋 ID 필요)
