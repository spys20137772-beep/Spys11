# 찰떡 점프 (Chaltteok Jump)

어디든 달라붙는 찰떡을 당겼다 놓아 날리는 물리 점프 게임. 부엌 · 정원 · 밤하늘 3개 월드, 24스테이지.

## 실행
- 웹: `npm run serve` → http://localhost:8081
- 데스크톱: `npm start`, 윈도우 빌드: `npm run dist:win`

## 조작
- 마우스/터치: 화면을 당겼다 놓기 (반대 방향으로 날아감)
- 키보드: ←→ 방향, ↑↓ 힘, Space 발사 · R 다시 시작 · Esc 일시정지
- 게임패드: 왼쪽 스틱 조준, A 발사, Y 다시 시작, Start 일시정지

## 장치
`#` 붙는 블록 · `^` 가시 · `C` 나무 상자(세게 부딪히면 부서짐) · `I` 유리(미끄러움) · `B` 버섯(튕김) · `F` 체크포인트 · `~` 과자(곧 부서짐) · `U` 바람개비(위로 날림)

## 검증
- `node tests/solve.mjs`: 실제 게임 물리로 모든 스테이지와 딸기를 자동으로 풀어 클리어 가능함을 증명
- `tests/full.cjs`: 풀이 경로로 24스테이지를 실제 게임에서 엔딩까지 진행 + 조작/저장/폰 검사
